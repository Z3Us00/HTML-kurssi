Iso päivitys

Teknologiajätti julkaisi tänään odotetun päivityksen suosittuun komentorivityökaluunsa. Käyttäjien kannattaa ladata uusin versio välittömästi suorittamalla pääteikkunassa komento npm update -g tech-cli. Päivitys korjaa kriittisen tietoturvavirheen, joka liittyy virheellisesti määritettyyn config.json-asetustiedostoon. Mikäli päivityksen jälkeen ilmenee ongelmia, järjestelmän voi palauttaa aiempaan tilaan syöttämällä tech-cli --rollback.
