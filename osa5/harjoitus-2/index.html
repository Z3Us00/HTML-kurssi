Ohje sivusto

Ohjeet github pages:in asennukseen

  1. Luo github käyttäjä, jos sinulla ei ollut jo aikaisemmin. Ja luo uusi repositio.
  2. Lisää html tiedosto repoon, git push:illa tai tai githubin UI:n kautta
  3. Avaa repositio asetukset ja valitse pages
  4. Valitse Main tai Branchin alta kansio /root ja tallenna
  5. Odota hetki kun git rakentaa sivuston automaattisesti
  6. Voit nyt kokeilla avaamalla sivun formaatilla https://käyttäjä.github.io/repo-nimi
